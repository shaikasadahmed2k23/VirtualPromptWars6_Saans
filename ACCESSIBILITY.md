# Accessibility (WCAG 2.2 AA)

Measured on 2026-11-19. Automated checks: **vitest-axe reports zero violations on 6 whole-page states**, and **Lighthouse 12.8.2 scores Accessibility 100** on the live site in both mobile and desktop presets. Its `color-contrast`, `target-size`, `label`, `button-name`, `link-name` and `html-has-lang` audits all pass. Lighthouse audits the first screen only, so the deeper states are covered by the axe tests below.

## axe-clean states

`expectNoAxeViolations` in [web/src/app.test.tsx](web/src/app.test.tsx) asserts `violations` equals `[]` on the whole page in each of these states:

1. Initial, with no location chosen
2. Air quality loaded for a searched city
3. Plan loading
4. Air-quality error with retry
5. English plan shown
6. Hindi plan shown, with `<html lang="hi">`

```bash
npx lighthouse@12.8.2 https://virtualpromptwars6-saans.onrender.com --only-categories=accessibility \
  --chrome-flags="--headless=new --disable-features=CrossOriginOpenerPolicy,BrowsingContextGroupSwap --disable-site-isolation-trials"
```
